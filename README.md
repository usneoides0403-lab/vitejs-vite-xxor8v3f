# 🏬 店内レイアウト3D

店内を自由にレイアウトできる 3D モデルツールです。棚・冷蔵ケース・レジなどの什器を
ドラッグで並べ、俯瞰／間取り図／店内ウォークスルーの 3 つの視点で確認できます。
React + Vite + three.js の単独アプリで、サーバは不要（データは端末に保存）です。

## できること

| | 操作 |
| --- | --- |
| 什器を置く | 右（スマホは下）の「什器を追加」からタップ。売場 / 客席 / 厨房 / 建具の4分類・全30種類 |
| 台の上・頭上に置く | 「選択中」の「床から」で設置高さを指定。レンジフード・換気扇・電子レンジなどに使う |
| 動かす | 3D画面で什器を**ドラッグ**。グリッド吸着（自由 / 10 / 25 / 50cm）で通路幅もそろう |
| 向き・大きさ・色 | 什器を選ぶと「選択中」タブでサイズ(m)・角度・色・名前を変更 |
| 視点 | **俯瞰**（回して眺める） / **真上**（間取り図のように編集） / **店内**（一人称で歩く） |
| 店内を歩く | 「店内」でドラッグして見回し、WASD・矢印キー・画面のパッドで移動。什器と壁には当たり判定あり |
| 店の広さ | 「店の広さ」タブで幅・奥行・天井高を変更。テンプレート（和食店風 / コンビニ風 / スーパー風 / 空の店）も読み込める |
| 床材 | 「店の広さ」タブで板張り / 畳 / タイル / 土間を切り替え。畳は八畳敷き（縦横を組み合わせた敷き方）で描画 |
| 保存 | 端末に自動保存。JSON / PNG での書き出しと、JSON の読み込みに対応 |

ショートカット: `R` 回転 / 矢印キー 微調整 / `Delete` 削除 / `Ctrl+D` 複製 / `Ctrl+Z` 元に戻す / `Esc` 選択解除
（アプリ右上の「使い方」からも確認できます）

## 開発

```bash
npm install
npm run dev     # 開発サーバ
npm run build   # 本番ビルド
npm run preview # ビルド結果の確認
npm run lint    # ESLint
```

## ソース構成

- `src/App.jsx` … アプリのシェル（ヘッダーと「使い方」シート）
- `src/index.css` … 全体のスタイル
- `src/store3d/StoreLayout3D.jsx` … レイアウト画面のUI・状態管理（履歴・自動保存・入出力）
- `src/store3d/scene.js` … three.js のシーン（カメラ操作・選択・ドラッグ・一人称移動）
- `src/store3d/fixtures.js` … 什器カタログとモデル生成
- `src/store3d/presets.js` … テンプレートと配置ヘルパー
- `src/store3d/textures.js` … 板張り・畳・タイル・土間・塗り壁・木部・ステンレスのテクスチャ生成
- `src/store3d/saveFile.js` … JSON / 画像の保存（直接ダウンロードできない環境にも対応）

### テクスチャについて

画像ファイルは持たず、canvas に手続き的に描いて生成しています（起動時に約 0.3 秒）。
継ぎ目が出ないよう、ノイズの格子と模様の周期は canvas の幅に合わせてあります。
質感は色（map）と法線（normalMap）に加え、室内の映り込み（PMREM + RoomEnvironment）と
ACES トーンマッピングで作っています。

### 什器の種類

| 分類 | 什器 |
| --- | --- |
| 売場 | ゴンドラ棚・エンド平台・冷蔵ケース・冷凍平ケース・カゴ置き場・看板 / POP・観葉植物 |
| 客席 | テーブル席・座卓・小上がり（畳）・縁側・いろり・カウンター・レジ |
| 厨房 | 作業台・シンク（2槽）・ガスレンジ・レンジフード・業務用冷蔵庫・ステンレス棚・食洗器・電子レンジ・ホットプレート・換気扇 |
| 建具 | 入口・引戸 / 障子・間仕切り・柱・トイレ・手洗い |

小上がりの天端は畳、縁側は板張りで、什器の大きさに合わせて実寸で張られます。

### データ形式

レイアウトは次の JSON で表され、`localStorage`（キー: `store-layout-3d-v1`）に自動保存されます。

```jsonc
{
  "room": { "w": 12, "d": 9, "h": 3, "floor": "tile" }, // 幅・奥行・天井高（m）と床材
  "items": [
    {
      "id": "…",
      "type": "shelf",                        // fixtures.js の CATALOG にある種類
      "name": "お菓子",
      "x": -3.6, "z": -1.6,                   // 店の中心が (0, 0)
      "y": 0,                                 // 床からの設置高さ（m）
      "rotY": 0,                              // 向き（度）
      "w": 1.2, "d": 0.6, "h": 1.8,           // サイズ（m）
      "color": "#c9ced6"
    }
  ]
}
```
